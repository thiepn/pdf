# P18 real-world source evidence

Store **JSON metadata only** here. Do not commit source PDF/DOCX bytes, private filenames, extracted text, OCR text, passwords, screenshots, personal identifiers, or device serial numbers.

Create records from `docs/p18/real-world-case-template.json`. Every record is human-attested and tied to the frozen P17 product baseline by exact Git commit and to the local source document by SHA-256.

P18 requires coverage of: malformed, scanned, form-heavy, encrypted, signed, multilingual, and large.

One real document may cover several categories. Generated fixtures do not count as real-world evidence.
